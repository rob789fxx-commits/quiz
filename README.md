# 🧠 React Quiz App

A simple interactive quiz application built with React.

This project was created as part of my React learning journey to practice state management, component communication, conditional rendering, and handling user interactions.

## 🚀 Features

- ❓ **Multiple-Choice Questions** — Answer questions about React fundamentals.
- 📊 **Progress Bar** — Displays quiz progress as a percentage.
- ✅ **Answer Validation** — Checks whether the selected answer is correct.
- 🔢 **Score Tracking** — Counts the number of correct answers.
- 🏆 **Results Screen** — Displays the final score after completing the quiz.
- 🔄 **Restart Quiz** — Allows users to restart the quiz and try again.

## 🛠️ Technologies Used

- JavaScript (ES6+)
- SCSS
- React Hooks (`useState`)

## 🎮 How It Works

1. The application displays one question at a time.
2. Each question contains three possible answers.
3. The user selects an answer by clicking on it.
4. The application checks whether the answer is correct.
5. The progress bar updates as the user moves through the quiz.
6. After the final question, the application displays the total number of correct answers.
7. The user can restart the quiz using the **Try Again** button.
